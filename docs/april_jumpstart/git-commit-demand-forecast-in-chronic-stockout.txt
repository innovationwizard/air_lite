feat: uncensored demand metric — sale.order.line signal + forecast-diagnostic UI

DEALBREAKER 2 RESOLVED: Prophet was training on invoiced (supply-constrained)
quantities (metric='sales', from account.move.line). For SKU 77205001, this
produced a 35k/month forecast while the client's known demand is 45k+/month.
The gap is lost sales caused by chronic stockouts — invisible to the model
because censored observations look like low demand, not constrained supply.

ROOT CAUSE
----------
sale_orders.state values are stored in English ('sale'), not the Spanish label
visible in the Odoo UI ('Orden de venta'). All demand aggregation uses the
correct English filter.

SSOT LABEL
----------
sol_confirmed_order_date_qty_ordered_native_uom
  source    : sale_order_lines.quantity   (ordered qty, NOT delivered)
  date      : sale_orders.order_date      (demand arrival date)
  filter    : sale_orders.state = 'sale'  (confirmed orders only)
  cap       : observation_date <= 2026-01-31  (blind test cutoff)
